# Fonts

**Soria** (headings) — free under the SIL Open Font License 1.1, by Dani Bydani.
Download it from https://www.fontsquirrel.com/fonts/soria (or bydani.gumroad.com) and put the file here as:

- `Soria.woff2` (best — convert with fontsquirrel.com/tools/webfont-generator), and/or
- `Soria.ttf`

Until a file is here, headings use Fraunces (EUREKA's original serif) instead.
